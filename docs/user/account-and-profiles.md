# 👤 User Profiles & Multi-Account Management

ShortTV features a multi-profile user management system modeled after top streaming apps (Netflix, ShortMax, ReelShort).

---

## 🌟 Key Features

* **Multi-Profile Switching**: A single signed-in account can create up to 4 individual sub-profiles (e.g. *Personal*, *Kids / Safe*, *Romance Only*).
* **Custom Avatars & Nicknames**: Choose from 12+ bundled SVG avatars or upload custom profile images.
* **Profile PIN Lock**: Protect private watch histories and purchase wallets with an optional 4-digit PIN lock.
* **Authentication Options**:
  * **Google One-Tap / Firebase Auth**: 1-click seamless login across mobile and web.
  * **Email & Password**: Traditional secure registration with automated password recovery.
  * **Guest Mode**: Instant streaming with persistent localStorage syncing before formal sign-up.

---

## 🔒 Security & Privacy
* Each profile maintains an isolated watch progress index and private bookmark shelf.
* PIN-locked profiles prompt for credential entry upon profile selection.
