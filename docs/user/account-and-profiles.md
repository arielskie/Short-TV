# 👤 Account & Profile Management

User authentication, multiple profile creation, custom avatars, kid/adult rating restrictions, and profile PIN security.

---

## 📍 Where Users Access
Viewers click their avatar in the top navigation or visit **`/account/`**.

---

## 🛠️ User Features

* **Multi-Profile Support:** Users can create up to 5 unique viewing profiles per account (e.g., Mom, Dad, Kids, Guest).
* **Custom Profile Avatars:** Choose from 12+ Netflix-style vibrant cartoon and 3D avatar characters or upload a custom image.
* **Kid-Friendly Profile Mode:** Enabling Kids Mode automatically filters out mature content (16+ / 18+ titles) and presents family-safe reels.
* **Profile Lock PIN:** 4-digit PIN security lock to keep personal watch history and favorites private from other profile users.
* **One-Click Google Sign-In:** Instant authentication via Google Firebase OAuth without needing to remember complex passwords.
