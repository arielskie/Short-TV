# 🔐 Theme License & Domain Lock Settings

Manage your ShortTV theme license activation and restrict domain deployment to protect proprietary theme code.

---

## 📍 Where to Find
Go to **WordPress Admin → ShortTV Hub → Settings → Theme License & Domain Lock** tab.

---

## 🛠️ Configuration Fields

| Field | Description |
|---|---|
| **License Key** | Your unique purchased license key from CodeCanyon / ThemeForest or official distributor. |
| **Licensed Domain** | The registered production domain (e.g. `yourdomain.com`). |
| **Activation Status** | Shows whether the current installation is verified and eligible for automated updates and cloud endpoint presets. |
| **Staging / Localhost Mode** | Local development environments (`localhost`, `127.0.0.1`, `.local`, `.test`) are automatically granted unrestricted developer access. |
