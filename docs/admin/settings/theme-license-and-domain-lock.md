# 🔐 Theme License & Domain Lock Settings

Manage your ShortTV theme license activation, domain authorization, and official product support.

---

## 📍 Where to Find
Go to **WordPress Admin → ShortTV Hub → Settings → Theme License & Domain Lock** tab.

---

## 🛠️ Configuration Fields

| Field | Description |
|---|---|
| **License Key** | Your unique license key provided upon purchase by the official developer/seller (**Ayeng** | Website: [`ayengcoding.com`](https://www.ayengcoding.com/) | Telegram: [`@ayengcoding`](https://t.me/ayengcoding)). |
| **Licensed Domain** | The registered production domain for your platform (e.g. `yourdomain.com`). |
| **Activation Status** | Shows whether the installation is verified and active for automated cloud presets and feature updates. |
| **Staging / Localhost & LAN Mode** | Local development environments (`localhost`, `127.0.0.1`, `.local`, `.test`) and private LAN subnets (`192.168.x.x`, `10.x.x.x`, `172.16.0.0/12`) are automatically granted unrestricted developer access. |
