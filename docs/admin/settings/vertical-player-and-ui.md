# ▶️ Vertical Player & Mobile UI Settings

Customize the TikTok/Reel-style vertical player, auto-play behaviors, swipe gestures, video buffer intervals, and top/bottom navigation layouts.

---

## 📍 Where to Find
Go to **WordPress Admin → ShortTV Hub → Settings → Vertical Player & UI** tab.

---

## 🛠️ Player Options & Behaviors

| Setting | Description | Default / Recommended |
|---|---|---|
| **Auto-Play Next Episode** | Automatically plays the next episode upon completion of the current one. | `Enabled` |
| **Swipe Up / Down Gestures** | Enables seamless vertical swipe to navigate between episodes on mobile and touch devices. | `Enabled` |
| **Skip Intro Time (Seconds)** | Seconds to automatically skip drama opening intros when clicking "Skip Intro". | `85` seconds. |
| **Progress Tracking Interval** | Interval (in seconds) between automatic watch progress syncs to Firebase Realtime Database. | `15` seconds. |
| **Auto-Save Quality Preferences** | Remembers user's selected resolution (4K, 1080p, 720p, Auto HLS) across sessions. | `Enabled` |
| **Double-Tap to Like & Heart Animation** | Triggers Instagram/TikTok style glowing heart burst on double-tapping the video screen. | `Enabled` |

---

## 📱 Mobile Top Header Element Placement
In the **Mobile Header Layout** section, you can customize the placement of top header icons by moving them between:
* 👈 **Left Side Elements (Header Start):** e.g., Brand Logo, Coins Wallet.
* 🔍 **Center Area:** Floating Search Bar.
* 👉 **Right Side Elements (Header End):** e.g., Language Switcher, Notifications Bell, Watch History, User Avatar.
