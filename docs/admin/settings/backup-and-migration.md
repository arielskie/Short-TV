# 📦 Backup & Migration Settings

Export, import, and back up your platform configurations, section layouts, drama endpoint presets, and custom system settings.

---

## 📍 Where to Find
Go to **WordPress Admin → ShortTV Hub → Settings → Backup & Migration** tab.

---

## 🛠️ Operations

| Operation | Purpose |
|---|---|
| **Export Full Platform Backup (JSON)** | Downloads a complete JSON snapshot containing all ShortTV settings, UI layouts, endpoint presets, and paywall configurations. |
| **Import Platform Settings** | Upload a previously exported JSON backup file to instantly restore your configuration on a new server or staging environment. |
| **Reset Section Layouts to Defaults** | Resets homepage and navigation category sections back to default template presets. |
| **Restore All System Defaults** | Cleanses custom overrides and reverts the entire theme to factory baseline settings. |
