# 💎 Subscription & Coins Paywall Settings

Configure VIP membership tiers, pricing packages, paywall triggers, and coin unlock rules for premium drama episodes.

---

## 📍 Where to Find
Go to **WordPress Admin → ShortTV Hub → Settings → Subscription & Coins Paywall** tab.

---

## 🛠️ Pricing & Membership Configuration

| Feature | Description | Example Values |
|---|---|---|
| **Enable Paywall** | Activates coin locks and VIP subscription requirements on protected episodes. | `Enabled` |
| **Currency Symbol** | Currency displayed on pricing tables and coin shop. | `$`, `€`, `£`, `₱`, `₹` |
| **Basic Plan Price** | Monthly price for Basic Tier (Standard HD, 1 Device). | `$9.99 / mo` |
| **Standard Plan Price** | Monthly price for Standard Tier (Full HD 1080p, 2 Devices). | `$15.49 / mo` |
| **Premium Plan Price** | Monthly price for Premium VIP (4K Ultra HD + HDR, 4 Devices, Unlimited Free Episodes). | `$19.99 / mo` |
| **Coins Per Episode Unlock** | Default number of coins deducted when a free user unlocks an episode. | `100` to `200` Coins. |
| **Daily Check-In Reward** | Number of bonus coins given to users daily under the Rewards Center. | `+100` Coins / Day. |

---

## 🔓 How Users Unlock Locked Episodes
1. **VIP Subscription:** Active VIP members immediately bypass all coin locks and watch unlimited episodes.
2. **Coin Balance:** Users can spend earned or purchased coins (e.g. 100 coins per episode).
3. **Rewarded Ads:** Free users can watch a short video ad to claim free coins.
4. **Daily Check-In:** Log in daily to claim free reward coins.
