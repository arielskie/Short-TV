# 🎬 Splash Screen & Launch Animation Settings

Configure the cinematic launch screen that plays when viewers first enter your streaming app or website.

---

## 📍 Where to Find
Go to **WordPress Admin → ShortTV Hub → Settings → Splash Screen** tab.

---

## 🛠️ Configuration Options

| Option | Description | Options / Recommendations |
|---|---|---|
| **Splash Screen Mode** | Visual animation style presented during initial app loading. | `Netflix-Style Monogram Ribbon`, `Custom Logo Reveal`, `Minimalist Typography`. |
| **Splash Background** | Background tone for the introduction sequence. | `#121212` (Cinematic Deep Obsidian) or custom dark gradient. |
| **Glow & Accent Color** | Ambient glowing radial light behind the brand symbol. | Brand primary red/crimson (`#E50914`) or neon cyan. |
| **Animation Duration** | Total duration before smoothly transitioning to homepage feed. | `1.5s` to `2.2s` for optimal user experience. |
| **Display Frequency** | How frequently returning viewers see the launch screen. | `Every Visit`, `Once Per Session` (Recommended), or `Once Per Day`. |

---

## 💡 Best Practices
* Set display frequency to **Once Per Session** so regular returning users can jump straight into viewing content without delays.
