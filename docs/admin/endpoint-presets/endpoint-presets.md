# ⚡ Endpoint Presets & Auto-Scraper

Quickly import drama catalogs, bulk ingest episode feeds, test API endpoints, and configure automated content syndication.

---

## 📍 Where to Find
Go to **WordPress Admin → ShortTV Hub → Endpoint Presets**.

---

## 🛠️ Features Overview

* **One-Click Catalog Ingestion:** Import drama series packages with pre-populated posters, synopsis, tags, and streaming URLs.
* **REST & JSON API Compatibility:** Supports custom JSON schema formats for external video storage repositories and CDN buckets.
* **Live Connection Tester:** Validate upstream API keys, bearer tokens, and endpoint responsiveness with real-time status diagnostics.
* **Automated Episode Syncing:** Check for newly added episodes on external sources and automatically append them to published drama series.
