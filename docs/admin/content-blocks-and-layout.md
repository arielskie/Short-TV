# 🗂️ Content Blocks & Visual Layout Builder

Customize the homepage layout, featured hero banners, trending carousels, genre tabs, and custom curated rows with a live visual drag-and-drop builder.

---

## 📍 Where to Find
Go to **WordPress Admin → ShortTV Hub → Content Blocks**.

---

## 🛠️ Section Types & Components

| Block Type | Description | Display Options |
|---|---|---|
| **Featured Hero Billboard** | Massive top hero carousel with auto-rotating trailers, title logo, match badge, and quick Play/My List buttons. | Fullscreen 16:9 or Vertical 9:16 spotlight. |
| **Top 10 Global Trending Row** | Curated row with large stylized numerical ranks (`#1` to `#10`) and badge indicators. | Automatic by view count or manually pinned. |
| **Episodic Carousel Rows** | Netflix-style horizontal sliding shelves filtered by category or genre tags. | Standard Poster (9:16) or Wide Landscape (16:9). |
| **Genre & Mood Filter Bar** | Horizontal pill filters allowing viewers to filter dramas by mood (e.g. *Action, Billionaire, Romance, Thriller*). | Multi-select with instant AJAX filtering. |
| **Continue Watching Row** | Dynamically appears for logged-in users with a red progress bar indicating exact timestamp progress. | Auto-synced via Firebase Realtime Database. |
